# Y7 Sport 1.1.8 — сервер 10.2.4.44 (Windows)

Цей пакет запускайте на **10.2.4.44**, під тим самим обліковим записом Windows, де стоятиме AceStream. Папка встановлення: `C:\Y7SportBridge`. Lampac у `C:\K2LampacSecure`, Gateway, спарювання, ігри й Tailscale інсталятор не змінює.

## 1. Встановлення AceStream

1. На сервері відкрийте [офіційні завантаження AceStream](https://docs.acestream.media/products/), виберіть Windows / Ace Stream Media. Альтернативний [офіційний сайт](https://www.acestream.org/en/). Установлюйте саме Engine/Media, а не сторонній браузер з подібною назвою. Бінарний інсталятор не вкладений у цей ZIP.
2. Запустіть завантажений інсталятор, перевірте його видавця у Windows і завершіть встановлення. Компонент `Ace Stream Engine` обов’язковий. Не потрібні розширення браузера, щоб передавати відео у Lampa.
3. Запустіть `START_ACESTREAM.ps1` через PowerShell. Він знаходить engine поточного користувача та перевіряє API на `127.0.0.1:6878`. Якщо шлях інший: `powershell -NoProfile -ExecutionPolicy Bypass -File .\START_ACESTREAM.ps1 -EngineExe "D:\ACEStream\engine\ace_engine.exe"`.
4. У налаштуваннях AceStream увімкніть запуск engine після входу цього користувача у Windows. Наш інсталятор не змінює конфігурацію стороннього engine. Для роботи після перезавантаження цей користувач має увійти у Windows. Не вмикайте автоматичний вхід з паролем лише заради цього пакета.

Стандартний шлях `%APPDATA%\ACEStream\engine\ace_engine.exe` та запуск описані в [офіційній документації](https://docs.acestream.media/developers/running-engine-desktop/). `acestream://ID` не є HLS: engine перетворює доступну P2P-трансляцію на локальний HLS. Потрібні активні peers і підтримуваний кодек; engine не гарантує наявність конкретного матчу чи безкоштовність усіх режимів.

## 2. Встановлення Sport Bridge

1. Встановіть **Python 3.11 або новіший** з [python.org](https://www.python.org/downloads/windows/), увімкніть додавання Python у PATH. Git і бібліотеки pip для Bridge не потрібні.
2. Розпакуйте весь ZIP, наприклад у `C:\Y7SportInstall118`. Для ручної перевірки запустіть `python -m unittest discover -s tests -v` з цієї папки.
3. Відкрийте **PowerShell від адміністратора**, перейдіть до розпакованої папки й виконайте `powershell -NoProfile -ExecutionPolicy Bypass -File .\INSTALL_SERVER.ps1`.
4. Інсталятор перевірить, що це саме сервер 10.2.4.44, збереже попередні файли, створить приватний ключ, окреме завдання «Y7 Sport Bridge» і правило Windows Firewall для TCP 9122 у приватній/доменній мережі. Він не відкриває порт AceStream 6878.
5. Виконайте `powershell -NoProfile -ExecutionPolicy Bypass -File .\CHECK_SERVER.ps1`. Очікується `bridge.ok: true` і `check.engine.available: true`. Цей звіт можна надіслати без ключа. Після перезапуску сервера завдання Bridge стартує під час входу користувача.

Якщо телевізор через іншу підмережу/VPN, адміністратор може явно задати його адресу: `INSTALL_SERVER.ps1 -AllowedClients "IP_ТЕЛЕВІЗОРА"`. Типове `LocalSubnet` не відкриває доступ з Інтернету. Не створюйте переадресацію 6878/9122 на роутері. Ключ у `C:\Y7SportBridge\bridge-config.json` і приватні резервні копії **не завантажувати в GitHub**.

## 3. Підключення Lampa / LG

1. В існуючому плагіні Спорту замініть URL на `https://yuroc7.github.io/lamp/y7_sport.js?v=118`, повністю перезапустіть Lampa. Дублікат плагіна не додавайте.
2. Y7 Спорт → Налаштування → Адреса сервера: `http://10.2.4.44:9122`.
3. На сервері відкрийте приватний `bridge-config.json`, скопіюйте **лише значення `access_key`** у поле «Ключ доступу» Lampa. Воно зберігається у локальному сховищі цього клієнта, не у публічному feed. Очищення даних Lampa видаляє налаштування.
4. Натисніть «Перевірити сервер та AceStream». Далі відкрийте матч → джерело / «Автоматично». Для власного ID є пункт «Відкрити власний AceStream ID».
5. Якщо Lampa запущена з **HTTPS**, браузер може заблокувати запит до локального **HTTP** (mixed content / local network permissions). Спочатку перевірте доступ до `/health` з телевізора. Використайте доступну вам HTTP-версію локальної Lampa або окремий довірений HTTPS reverse proxy до Bridge. Наявний Gateway/Tailscale цей пакет автоматично не перебудовує. Самопідписаний недовірений сертифікат LG може відхилити. Дозвіл локальної мережі в браузері — окрема перевірка.

Bridge підтримує HTTPS-проксі з префіксом шляху: у Lampa задайте повну базову адресу на кшталт `https://YOUR-HOST/sport-bridge`; проксі має прибирати префікс і зберігати Authorization. Доступ закрийте на вашому проксі. Не додавайте ключ до URL/логів. Шляхи `/media/` містять тимчасові секрети сесій: вимкніть журналювання URL для цього маршруту. Для клієнта мають бути доступні і `/api/`, і `/media/` через одну базову адресу.

## 4. Що підтримується і що перевіряти

- LiveTV, DaddyLiveHD, PPV, TimStreams, PitSport: каталог подій та посилання на конкретні джерела. При натисканні сервер заново перевіряє джерело. Якщо є явний відкритий HLS і справжній відеосегмент — запускає Lampa Player. Якщо сайт віддає лише HTML/динамічний плеєр — помилка `NO_NATIVE_MEDIA`; рекламна сторінка не відкривається. Кількість джерел не означає кількість перевірених відеопотоків.
- AceStream: 40-символьні ID з LiveTV або ваш ID → локальний Engine → HLS → Lampa Player. Після закриття відправляється stop; покинуті сесії видаляються після 180 секунд без запитів.
- SopCast: розпізнається у метаданих, але відтворення не реалізоване; [LiveTV також повідомляє про припинення підтримки](https://livetv-ru17.me/enx/faq/). Не встановлюйте його в очікуванні роботи цього плагіна.
- DRM, VIP, захищені API, підписки не обходяться. Bridge не виконує сторонні скрипти і не повертає iframe замість відео. Повноекранне відео залежить також від кодека, CORS/мережі й можливостей webOS.
- Перед релізом є локальні автоматичні тести, включно з HTTP-моделлю AceStream та реальними байтами тестових TS-сегментів. **Це не підтверджує інсталяцію на 10.2.4.44 і не є тестом реальної спортивної трансляції на LG.**

Перевірка на телевізорі: матч → відео; понад 6 хвилин без натискання кнопок — акваріум Y7 не з’являється; Назад → звичайна навігація; через 5 хвилин бездіяльності акваріум відновлюється; зламане джерело → зрозуміла помилка/резерв. Окрема системна заставка Lampa/webOS перевіряється окремо.

## 5. Відкат

`powershell -NoProfile -ExecutionPolicy Bypass -File .\REMOVE_SERVER.ps1` від адміністратора прибере лише завдання Bridge і його правило Firewall. Файли, ключ і backups лишаться. Для повернення попередньої версії зупиніть завдання, відновіть `y7_sport_bridge.py` з відповідного timestamp у `C:\Y7SportBridge\backups`, запустіть завдання знову. Конфігурацію відновлюйте лише якщо її теж міняли. Не публікуйте backups.

AceStream видаляється окремо стандартним пунктом Windows «Встановлені програми». Наявний Lampac/Gateway не потрібно перевстановлювати. Для відкату самого плагіна використайте скрипт із повного релізного архіву Y7 Sport.
